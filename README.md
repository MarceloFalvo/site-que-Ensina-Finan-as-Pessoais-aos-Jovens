MF Invest — Educação Financeira Gamificada

O MF Invest é um projeto fictício que desenvolvi para aprendizado e prática de desenvolvimento front-end. A proposta do site é ensinar educação financeira para jovens de forma moderna, simples e interativa, utilizando elementos de gamificação para tornar a experiência mais divertida.

Durante o desenvolvimento, pratiquei conceitos como criação de interfaces responsivas, sistema de login e cadastro, armazenamento de dados com LocalStorage e animações modernas utilizando HTML, CSS e JavaScript.

O projeto foi criado com foco em melhorar minhas habilidades em desenvolvimento web, design de interfaces e experiência do usuário, além de servir como projeto para estudos e portfólio.
